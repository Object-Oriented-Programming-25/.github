## 📥 Langkah Pengumpulan:

1. **Klik Link Assignment** dari dosen
2. **Authorize** GitHub Classroom jika diminta
3. **Accept assignment** - otomatis tercreate repo fork di akun Anda
4. **Clone repo** ke komputer:
   ```bash
   git clone https://github.com/Object-Oriented-Programming-25/[nama-repo].git
   ```

## 💻 Kerja & Upload:

1. **Buat folder** dengan format: `[NIM]-[NAMA]-[Modul]`
2. **Masukkan file** praktikum ke folder tersebut
3. **Commit & push**:
   ```bash
   git add .
   git commit -m "Jurnal modul 1 - [NIM]"
   git push origin main
   ```
